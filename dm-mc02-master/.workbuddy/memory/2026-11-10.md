# 2026-11-10

## 关键发现：少接一台电机 → 同总线其他电机"能转不了"
- 现象：1 号电机不接入时，3 号电机**能使能但不能转**；接上 1 号后 3 号恢复正常。
- 机理（CAN 协议层）：固件向不存在的 CAN ID 发帧，无人 ACK，**发送错误计数 TEC 每帧 +8**，涨到 256 即 **BUS-OFF**，整条总线瘫痪。按 500Hz 发帧计算，**30~50ms 就会打死总线**。
  - 使能帧发生在总线被打死之前发出 → 电机灯变绿（已使能），但之后控制帧全丢 → 转不了。与现象完全吻合。
  - 接上 1 号 → 有人 ACK → TEC 不涨 → 总线健康 → 3 号正常。
- 这也是此前反复出现的"配 6 台只接 3 台就全不动""配 3 台只接 1 台没反应"的同一个根因。

## 修复：只给"回过话"的电机发帧（母版已改）
`App/dm_ctrl_task.c`：
- 新增 `s_online[]`、`s_any_online`；
- 探测兜底阶段记录每台 `s_online[i] = m->online`；
- 初始使能、周期性补使能帧都只发给 `s_online[i]` 的电机；
- 主循环每轮先刷新 `s_online[]`（`m->online` 一旦为 1 就永久保留 → **中途插入的电机自动加入**），再跳过离线台；
- **兜底**：若一台都没在线（判定失败），则退回"全部发"，避免再现"全停"。
