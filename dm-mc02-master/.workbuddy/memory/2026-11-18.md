## 新建：06_模式实验（教学模式/速度调节）
- 需求：用户想学习电机各种控制模式与速度调节；同时确认"线坏的电机先不装、不接是否影响其他电机"。
- **少接电机的结论：不影响**。`04`/`06` 主循环都有 `if (!m->online) continue;`，没回话的一帧都不发，不会把总线打进 BUS-OFF。探测阶段每台 10 帧，2 个空 ID = 20 帧无应答 → 错误计数 160 < 256，安全。若长期只跑 3 台，建议把 `DM_MOTOR_NUM` 与 `dm_cfg` 行数一起改小，最干净。
- `06_模式实验` 位置：`D:\singlechip\MC02_Labs\06_模式实验\`（由 04 复制）。编译通过 `Code=78978`。
- 核心设计：**用 `DM_MODE` 一个宏切换四种"模式"**，逻辑只有一段 `#if/#elif`：
  | 模式 | pos | vel | kp | kd | tau |
  |---|---|---|---|---|---|
  | HOLD 锁定 | 原位 | 0 | 20 | 2 | 0 |
  | ROTATE 匀速转 | 实际+步长 | 目标速度 | 20 | 2 | 0 |
  | VELOCITY 速度 | 0 | 目标速度 | 0 | 3 | 0 |
  | TORQUE 力矩 | 0 | 0 | 0 | 0 | 1 |
- 关键认知（讲给用户）：达妙所谓"位置/速度/力矩模式"并不是电机的不同模式，**只是 MIT 帧里 5 个量的填法不同**。CTRL_MODE 始终是 1（MIT）。
- 参数：`ROT_SPEED=0.5 rad/s`、`ROT_DIR=-1`、`POS_KP=20`、`POS_KD=2`、`VEL_KD=3`、`TQ_TAU=1.0`、`PERIOD_MS=2`、`PROBE_NUM=10`。
- 安全提示：TORQUE 模式 kp=kd=0，无任何速度约束，空载会持续加速，测试时间要短。
- 保留了每 2 秒的 `在线/累计帧/位置` 打印（丢帧诊断用）。
